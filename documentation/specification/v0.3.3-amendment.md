# CADOM Spec v0.3.3 — amendment notes

**Date:** 2026-09-16  
**Base:** v0.3.2  
**Change type:** additive minor (`version_minor = 6`)  
**Issue:** [#55](https://github.com/naanouff/OpenCAD/issues/55)  
**Doctrine:** [`../opencad-doctrine.md`](../opencad-doctrine.md) (B3′)

## What changed

- New native kind `AssetKind.CADOMBREP` (`.cadombrep`) — **dead B-Rep envelope**
- Role `EXACT` **re-activated** in the OpenCAD truth model for **CADOMBREP only**
- Complete profile **MUST** bind `PARAMETRIC` + `MESH` + `EXACT` on part occurrences
- STEP remains **LEGACY** / out of truth model (import sas only)
- Stub spec: [`cadombrep-v0.md`](cadombrep-v0.md) + [`cadombrep.proto`](../../packages/cadombrep-proto/cadombrep.proto)

## Compatibility

- Additive enum value `CADOMBREP = 9`
- Older readers that ignore unknown enum values **MAY** round-trip assets if unknown-field policy allows
- Writers of Complete products **MUST** emit `EXACT` → `CADOMBREP`, **MUST NOT** emit `EXACT` → `STEP`
