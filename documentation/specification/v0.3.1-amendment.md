# CADOM Spec v0.3.1 — amendment notes

**Date:** 2026-09-15  
**Base:** v0.3  
**Change type:** additive minor (`version_minor = 4`)  
**Issue:** [#49](https://github.com/naanouff/OpenCAD/issues/49)  
**Driver:** [cadom-spec-swot.md](../cadom-spec-swot.md) P0 (+ cadompart P2 posture)

## What changed (core `.cadom`)

- Two-layer identity rewrite (§1): core orchestration vs optional native family
- Asset role `EXACT` for STEP / B-Rep (distinct from `MESH`)
- `LengthUnit`: millimetres and inches (UNSPECIFIED still = metres)
- Sibling order = appearance order in `nodes[]`
- `CadomFile.default_active_layers`
- `Asset.content_sha256` / `byte_length`
- MIME `application/vnd.opencad.cadom`; precision policy for float32 vs double authoring
- Filename `cadom-v0.1.md` documented as historical; package `cadom.v0_1` frozen

## What changed (cadompart posture)

- Geometric truth without rebuild = STEP (`EXACT`) and/or cadomesh
- Required rebuild remains narrow (sketch + extrude/revolve/hole/boolean)
- Non-empty `expression` forbidden until a versioned dialect exists
- Open CASCADE named as reference rebuild engine (profile TBD)

## Superseded in part

Doctrine **v0.3.2** / [#51](https://github.com/naanouff/OpenCAD/issues/51) removes STEP/`EXACT` from the OpenCAD truth model. Keep mm, sibling order, default layers, hash, MIME from this amendment.
