# CADOM Spec v0.1 — freeze notes (SPEC-11)

**Freeze date:** 2026-09-14  
**Status:** draft frozen — ready for SDK implementation sprint

## Prose ↔ proto consistency checklist

- [x] `CadomFile` version, units, up_axis, root_ids, nodes, assets, overrides, extensions
- [x] `Node` id, parent_id, name, local_transform (0 or 16 floats), asset_id, visible (optional), semantic_type
- [x] `Asset` id, uri, kind, mime
- [x] `Override` node_id, layer, optional visible/material_ref, local_transform patch
- [x] `Extension` vendor, type, payload bytes
- [x] Enums: LengthUnit, UpAxis, AssetKind
- [x] Pass-through and unknown-field policy documented (§6, §7.3)

## Deferred decisions (explicitly out of v0.1)

1. Multi-file archive / zip container for `.cadom` + assets
2. Sibling ordering guarantee among children
3. Active override layers stored inside the document (currently session/app)
4. Formal public extension registry
5. Binary fixture `.cadom` files (blocked on SDK encode)
6. Material model beyond opaque `material_ref` string
7. Additional length units beyond metres

## Next sprint

Bootstrap monorepo tooling, generate TS from `cadom.proto`, implement `@opencad/cadom` with **TDD** (decode/encode, overrides, pass-through).
