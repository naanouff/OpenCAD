# CADOM Spec notes — Control and Manufacturing (v0.3.5)

**Date:** 2026-11-20  
**Base:** CADOM v0.3.3 (`version_minor = 6`)  
**Change type:** additive minor (`version_minor = 7`)  
**Issue:** [#97](https://github.com/naanouff/OpenCAD/issues/97)

v0.3.4 amended **cadompart** only and did not change `CadomFile.version_minor`.

## What changed

- `AssetKind.CADOMFAB` (10) and `AssetKind.CADOMCTRL` (11)
- `AssetRole.MANUFACTURING` (6) and `AssetRole.CONTROL` (7)
- Companions [cadomfab-v0.md](cadomfab-v0.md) and [cadomctrl-v0.md](cadomctrl-v0.md)
- Doctrine profiles **Control** and **Manufacturing**: control writes adjustment values for parameter ids declared by the gamme; it does not edit the gamme

## Compatibility

- Additive enum values. v0.3.3 readers **SHOULD** round-trip unknown kinds and roles.
- Writers that emit `CADOMFAB` or `CADOMCTRL` **MUST** set `version_minor = 7`.
- Files that do not use these kinds **MAY** stay at `version_minor = 6`.
- `@opencad/cadom` on `develop` still exposes the v0.3.3 unions (`version_minor = 6`). Recognizing the new kinds in that SDK is a follow-up; this revision defines the wire and the prose.

## Non-goals

Material-removal simulation, PMI, arcs, and 5-axis toolpaths are not part of this amendment.
