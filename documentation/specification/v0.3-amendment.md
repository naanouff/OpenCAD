# CADOM Spec v0.3 — amendment notes

**Date:** 2026-09-14  
**Base:** v0.2  
**Change type:** additive minor (`version_minor = 3`)

## What changed

- Nodes reference **multiple assets** via `asset_bindings` / `NodeAssetBinding`
- Roles (at most one each): `MESH`, `PARAMETRIC`, `MATERIAL`, `METADATA` (v0.3.1 adds `EXACT`)
- New `AssetKind`: `CADOMETA` (`.cadometa`)
- Legacy `Node.asset_id` kept as deprecated alias for a `MESH` binding

## Compatibility

- v0.2 files with only `asset_id` remain readable (§3.3.2)
- v0.3 writers **SHOULD** use `asset_bindings` exclusively

## Native schemas

Detailed binary schemas for `.cadomesh`, `.cadompart`, `.cadomat`, `.cadometa` are **no longer deferred** — see the native companion specs under this directory and the [native assets freeze](native-assets-v0-freeze.md).

## Follow-up

See **v0.3.1** (`version_minor = 4`) for SWOT hygiene, then **v0.3.2** ([#51](https://github.com/naanouff/OpenCAD/issues/51)) for doctrine B3+K3 (STEP/`EXACT` out of truth model).
