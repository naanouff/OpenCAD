# CADOM Spec v0.3.2 — amendment notes

**Date:** 2026-09-15  
**Base:** v0.3.1  
**Change type:** editorial / doctrine minor (`version_minor = 5`)  
**Issue:** [#51](https://github.com/naanouff/OpenCAD/issues/51)  
**Doctrine:** [`../opencad-doctrine.md`](../opencad-doctrine.md)

## What changed

- Fil rouge: orchestration + rebuild co-primary; Complete = graph + parametric + mesh + kernel
- STEP / `EXACT` removed from OpenCAD **truth model** (legacy enum values may remain on the wire)
- OpenCAD Kernel (K3) named as product rebuild engine; cadomesh = viz without kernel
- `default_active_layers` retained

## Compatibility

- No required proto field renumbering
- Writers of OpenCAD products **MUST NOT** emit `STEP` / `EXACT` as truth
- Readers **MAY** still round-trip legacy bindings
